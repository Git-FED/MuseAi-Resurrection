A portable, honest transfer kit for rebuilding an AI agent's operating context after a host, account, or workspace change.

## Shortest honest answer
No single archive recreates an operating agent. Restore identity, memory, handoff, credentials, connections, schedules, and proof.

## Five-stage flow
Package → Import → Reconnect → Schedule → Prove

## Safety boundary
This repository contains documentation, templates, validation tools, and safe examples. It never stores secrets and does not support token evasion, account abuse, credential theft, or deceptive multi-account rotation.

Start with [QUICKSTART.md](QUICKSTART.md), then read [THREAT-MODEL.md](THREAT-MODEL.md) and [docs/RESURRECTION.md](docs/RESURRECTION.md).
